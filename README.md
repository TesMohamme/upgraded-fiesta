# الكفرة ماركت | Kufra Market

المستودع المخصص لمشروع **الكفرة ماركت** وتطوير موقعه وتطبيقه.

## حالة المشروع

لم تُنقل ملفات مصدر الموقع الكامل إلى هذا المستودع بعد. ملفات Python الموجودة مسبقاً محفوظة كما هي. تخصيص المستودع لا يعني تفعيل المزامنة أو النشر التلقائي.

## النطاق

- واجهة عربية متجاوبة، وألوان الشعار، وخط Cairo Black للعناوين.
- عرض الأقسام والإعلانات وصفحات تفاصيل المنتجات.
- حسابات العملاء الليبيين وملفاتهم وتحديث أرقام واتساب.
- نشر الإعلانات للعملاء المعتمدين فقط، بالدينار الليبي.
- إدارة حالة المنتجات وحذفها ومشاركتها.
- لوحة إدارة محمية لإدارة العملاء وصور المنتجات والعدادات وصور الواجهة ورقم واتساب وبيانات دخول الإدارة.

## التطوير والنشر

يُستخدم هذا المستودع للكفرة ماركت بدلاً من TesMoha. يجب نقل المصدر والتحقق منه قبل إعداد النشر. لا تُحفظ كلمات المرور أو مفاتيح التوقيع أو بيانات اتصال قاعدة البيانات الحقيقية في المستودع.
